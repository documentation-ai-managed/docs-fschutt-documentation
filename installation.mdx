## Installing Azul

Getting started with Azul is straightforward. Whether you're using Rust or C, the installation process is designed to be quick and painless. Azul provides pre-built binaries for all supported platforms, along with comprehensive documentation to help you set up your development environment.

<Steps>
  <Step title="Download Azul" icon="download">
    Visit the official Azul website and download the appropriate package for your operating system. We provide installers for Windows, macOS, and Linux distributions.
  </Step>
  <Step title="Run Installer" icon="play">
    Execute the installer and follow the on-screen instructions. The installer will automatically configure your system path and install all necessary dependencies.
  </Step>
  <Step title="Verify Installation" icon="check">
    Open a terminal and run `azul --version` to confirm the installation was successful.
  </Step>
</Steps>

## Rust Development Setup

For Rust developers, Azul integrates seamlessly with Cargo and the Rust ecosystem. The framework is distributed as a standard Rust crate, making it easy to include in your projects.

<Tabs>
  <Tab title="Cargo" icon="package">
    ## Using Cargo
    
    Add Azul to your `Cargo.toml`:
    
    ````toml
    [dependencies]
    azul = "0.1.0"
    ````
    
    Then build your project:
    
    ````bash
    cargo build --release
    ````
  </Tab>
  <Tab title="Cargo Workspace" icon="folder">
    ## Workspace Setup
    
    For larger projects, consider using a Cargo workspace:
    
    ````toml
    [workspace]
    members = ["app", "ui", "core"]
    
    [workspace.dependencies]
    azul = "0.1.0"
    ````
  </Tab>
</Tabs>

## C Development Setup

Azul provides C bindings that allow you to use the framework from C applications. The C API is designed to be familiar to C developers while providing the same performance benefits.

<CodeGroup tabs="Linux,macOS,Windows">
  ````bash
  # Ubuntu/Debian
  sudo apt update
  sudo apt install azul-dev
  ````
  ````bash
  # macOS with Homebrew
  brew install azul
  ````
  ````bash
  # Windows with Chocolatey
  choco install azul
  ````
</CodeGroup>

<Callout kind="info">
  The C development package includes header files, static libraries, and pkg-config files for easy integration with your build system.
  </Callout>

## Troubleshooting Installation

If you encounter issues during installation, here are some common solutions:

<ExpandableGroup>
  <Expandable title="Permission Errors" default-open="false">
    On Unix systems, you may need to run the installer with elevated privileges. Use `sudo` on Linux or run as Administrator on Windows.
  </Expandable>
  <Expandable title="Missing Dependencies" default-open="false">
    Ensure all system dependencies are installed. On Linux, you may need to install additional packages like `libx11-dev` or `libgl1-mesa-dev`.
  </Expandable>
  <Expandable title="Path Issues" default-open="false">
    If Azul commands are not found, check that the installation directory is in your system PATH environment variable.
  </Expandable>
</ExpandableGroup>
