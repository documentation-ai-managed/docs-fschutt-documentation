## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added support for custom shaders in WebRender integration
- Implemented advanced text rendering with font fallback support
- Introduced new animation APIs for smooth transitions
- Added support for high-DPI displays with automatic scaling

## Improvements

- Optimized memory usage in component rendering pipeline
- Enhanced C API bindings with better error handling
- Improved build times with incremental compilation
- Updated documentation with more comprehensive examples

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["breaking", "feature"]}>

## New Features

- Complete rewrite of the rendering engine for better performance
- Added support for Vulkan backend alongside existing OpenGL
- Implemented new component system with improved composability
- Added comprehensive accessibility features

## Breaking Changes

- Updated API signatures for component creation
- Changed event handling system to be more type-safe
- Modified build configuration requirements
- Updated minimum system requirements

</Update>

<Update label="2024-08-10" description="v1.5.0" tags={["feature", "bugfix"]}>

## New Features

- Added dark mode support with automatic theme switching
- Implemented drag-and-drop functionality for components
- Added support for custom window decorations
- Introduced new layout system with flexbox support

## Bug Fixes

- Fixed memory leak in long-running applications
- Resolved rendering artifacts on certain GPU configurations
- Fixed input handling issues with special keyboard layouts
- Corrected component sizing calculations in complex layouts

</Update>
